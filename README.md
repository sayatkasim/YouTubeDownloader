🎥 YouTube Video Downloader (1080p Max) - Python + yt-dlp

Bu Python betiği, kullanıcıdan bir YouTube video bağlantısı alır ve videoyu en fazla 1080p çözünürlükte olacak şekilde indirir.
yt-dlp kütüphanesini kullanarak hızlı ve esnek bir video indirme deneyimi sunar.

✨ Özellikler
Maksimum 1080p çözünürlük sınırı (daha yüksek çözünürlükler filtrelenir).
Videoyu masaüstüne, video başlığıyla isimlendirilmiş şekilde kaydeder.
Tüm platformlarda çalışabilir (Linux, macOS, Windows uyumlu yapılandırılabilir).
🛠 Gereksinimler
Python 3.6+
yt-dlp paketi (pip install yt-dlp)
🚀 Kullanım
python youtube_downloader.py
Program sizden bir YouTube bağlantısı ister, ardından indirme işlemini başlatır.

📁 Kaydedilen Dosya
Dosya, masaüstünüze şu şekilde kaydedilir:

~/Desktop/VİDEO_BASLIGI.mp4
⚠️ Uyarı
Bu araç yalnızca kişisel kullanım amaçlıdır. Telif hakkı içeren videoları izinsiz olarak indirmek yasa dışı olabilir. Lütfen YouTube'un hizmet şartlarına uygun şekilde kullanın.
